Name the concept

Model deployment means making the trained model usable in a real environment.

In plain language: move from “the model works for me” to “the model can reliably help users, apps or business processes make predictions.”

Reachable

An interface or service can send data to it.

Reliable

It behaves consistently in the target environment.

Useful

Its predictions can support practical decisions.

Why is deployment challenging?

The notebook and the real world are different environments.

⚡

Response time

Users expect predictions quickly when they call the model.

🧠

Model size + hardware

Large deep-learning models may need substantial CPU, GPU or TPU resources.

🔌

Compatibility

The production system may not match the languages or tools used during model development.

Step 1 · Route

The /predict route tells Flask which function handles prediction requests.

Local serving

127.0.0.1:8000 means: this computer.

Local Flask app

The server process is running on your own machine. Your browser can access it there.

http://127.0.0.1:8000/

Production/cloud app

The service runs on reachable infrastructure so approved users or other applications can access it over a network.

Large models need somewhere to live

A cloud bucket is a container for stored data and model files.

Amazon S3 / Google Cloud Storage

Both are cloud-storage services. A bucket can hold data and model files, including large trained models.

Important: storage holds the model. Something else still needs to run the inference computation.

AWS Lambda

Code that runs when an event happens.

Compute

Model/data

The function can retrieve packaged code, libraries and trained-model resources.

Observe

CloudWatch Logs can be used to inspect execution and validate inference activity.

First run vs later runs

Loading a large model can take time.

1st

Container starts

The model may need to be downloaded/loaded into memory before inference.

Next

Warm container

If the container remains available and the model is already in memory, later invocations can avoid repeating the full loading step.
